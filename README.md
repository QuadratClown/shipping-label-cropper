
# Shipping Label Cropper

Some companies distribute shipping labels that are embedded in bigger page sizes like A4 and need to be cropped to be able to print them in a label printer. The Shipping Label Cropper allows you to do just that.

It is based on the [DHL 4x6" Label Cropper](https://github.com/umbertoragone/DHL-4x6-label-cropper) to include custom formats, batch processing and vendors other than DHL. You can choose from predefined formats or define your own cropping format to crop arbitrary shipping labels to size. It allows batch cropping of multiple labels at once and printing directly from the browser.

## Features

- Executes fully local in browser
- Upload and crop transport labels to size
  - choose from predefined formats for DHL A4 4"x6" or 103mm x 199mm labels
  - define custom formats which are stored locally in your browser
- Supports Drag & Drop
- Supports multiple PDF files at once - all cropped labels will be merged into one file
- Supports multiple pages per PDF file
- Easy printing of cropped PDF files

## Usage

To use the Shipping Label Cropper, follow these steps:

1. Go to the website [quadratclown.github.io/shipping-label-cropper](https://quadratclown.github.io/shipping-label-cropper).
2. Select your label size or create your own
3. Open your labels (it works locally in the browser, no data is actually uploaded anywhere)
4. Download or print the cropped labels
